---
name: Write scripts to files for review
description: User prefers exploratory Python code written to files rather than run inline via Bash
type: feedback
---

Write Python scripts to files instead of running them inline in Bash, so the user can review the code before executing.

**Why:** User wants to see and review the code before it runs, especially for data exploration and analysis scripts.

**How to apply:** When writing exploratory/analysis Python code, save it as a `.py` file first. Let the user run it themselves.
